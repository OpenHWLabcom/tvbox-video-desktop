# 视频追剧版桌面小电脑 · 小主机改造方案 🖥️

把吃灰的安卓机顶盒，改造成一台**上网/办公小主机**：桌面 + 浏览器 + 中文输入 + 手机互传 + 接 U 盘，并做内存扩容与开机自愈。**不刷机**，风险低。

**六件套 + 基础设施：**
1. **瘦身** —— 去掉运营商/广告/无用后台
2. **内存扩容** —— zram + 分层 swap（存储当内存）
3. **桌面** —— 原生 Android 桌面 App（图标网格 / 双击 / 拖动 / 右键菜单）
4. **局域网互传 + 外接 U 盘** —— 纯标准库 HTTP 服务（`http://<盒子IP>:8890/`）
5. **浏览器** —— 老内核可用的火狐 + 桌面版 UA
6. **中文输入法** —— 配硬件键盘模式
\+ **显示/系统工具**（走本机服务 :8899）· **开机自启 + 兜底**

> 实测机型：海思 Hi3798MV100（HG680-J）、中兴微 ZX296715（B860AV1.1-T2）。其它 Android 4.4+ 的盒子大概率可用（未逐一验证）。

---

## 快速开始（3 步）

**1. 打开控制通道**：盒子开 ADB 调试 → 电脑 `adb connect <盒子IP>:5555`

**2. 一键安装**：进入 `安装文件/`，执行
```sh
./一键安装.sh <盒子IP>
```

**3. 用**：按 Home 选「桌面」为始终；插鼠标键盘；手机开 `http://<盒子IP>:8890/` 传文件。

完整图文步骤：**[安装教程](../安装教程.pdf)**（其它格式在 `安装教程（其它格式）/`）。
