# 常见问题

**Q：装不上 / “解析包错误”**
- 盒子安卓版本要 ≥ 4.1（本项目 targetSdk 19）。
- apk 要完整；用本包自带的 `桌面.apk`。

**Q：提示“未知来源 / 不允许安装”**
- 设置里打开「允许未知来源（允许安装非市场应用）」再装。

**Q：开机不自动进桌面**
- 按 Home 键，系统问“用哪个桌面”时选**桌面** → 始终。
- 有 root：`pm list packages | grep launcher` 看原桌面包名 → `pm disable <包名>`。
- 确认 init 自启那行已加（见教程第 10 步）。

**Q：开机卡在“正在升级/正在启动”的弹窗**
- 这是 ROM 的开机弹窗把桌面挡住了。`4-开机兜底.sh` 会自动反复关闭它并拉起桌面；确认它在 `/data/bootfix.sh` 且被 `startlinux.sh` 调用。

**Q：内存不够、卡、后台被杀**
- 跑一遍 `2-内存扩容.sh`（zram + swap）。确认 `cat /proc/swaps` 里三层都在。

**Q：手机打不开 `http://<盒子IP>:8890/`**
- 手机和盒子要在**同一 WiFi/局域网**；盒子 IP 在桌面「设置」或路由器里看。
- 确认互传服务在跑（`3-开机自启.sh` 里那行 / 手动 `python3 /root/transfer.py`）。

**Q：U 盘插上认不到 / 提示已拔出**
- FAT32 直接认；NTFS/exFAT 要用 Linux 子系统里 `ntfs-3g` 挂载（见手册）。

**Q：鼠标/键盘用不了**
- 这 ROM 通常只认 USB 鼠标+键盘（无触摸）。插 USB 口即可；有的盒子对供电挑，用带供电的 HUB。

**Q：装了自带浏览器打不开大网站**
- 老内核跑不动现代大网站是常态；用桌面「浏览器」打开简化页，或换能在你安卓版本上跑的火狐。

**Q：会不会联网/上传数据？**
- 桌面与脚本**完全离线、不联网、不上传**。只有「手机互传」走局域网。

**Q：想恢复原来的样子**
- `pm enable <被你禁用的包名>`；删掉 init 里 `startlinux.sh` 那行；卸载桌面 `pm uninstall com.openhwlab.desktop`。

**Q：改了桌面包名/换设备后桌面不自动起**
- 同步改 `4-开机兜底.sh` 里的 `HOME_PKG` 为新包名。
