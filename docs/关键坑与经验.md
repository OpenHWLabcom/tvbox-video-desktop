# 关键坑与经验（速查卡）

- **改桌面 App 代码 → 必须重启盒子**（`pm install -r` + `force-stop` 不够，旧进程跑旧 dex）。
- **改图标集合后位置错乱** → 清 `/data/data/<包名>/shared_prefs/*.xml`。
- **从 chroot 跑 Android 的 am/pm/settings/ime** → 必须 `chroot /proc/1/root /system/bin/sh -c ...` 且带 `BOOTCLASSPATH`，否则静默/`Aborted`。
- **chroot 里 `/data` ≠ Android 的 `/data`** → 写 Android 用 `/proc/1/root/data/...`。
- **chroot 服务要带 chroot 的 PATH**（否则子进程用安卓 PATH，找不到 `/usr/bin/*`）。
- **swap 文件必须放 ext4**；`/proc/swaps` 用真实路径比对；动态策略「加回自身、只增不减」。
- **USB 自动省电会掉盘/U盘** → `echo -1 > /sys/module/usbcore/parameters/autosuspend`。
- **老 WebView = Chromium 30** → 页面只用老 CSS（inline-block/float），别用 grid/flex/object-fit。
- **安卓 App 无真窗口** → 「最小化/缩放」只能是页面内部伪窗口。
- **浏览器界面语言跟系统 locale** → 要中文得装多语言版。
- **串口里别放中文/密钥**（会被截断）；busybox 常缺 head/free/ss/netstat。
- **`pkill -f '<串>'` 会连自己那条 ssh 一起杀** → 写脚本跑或锚定 `pkill -f '^/usr/bin/python3 /root/xxx.py'`。
- **老内核上限决定能跑什么**（Chromium ~81 / Firefox 68），大网站跑不动是常态，别强求。
- **验证三件套**：截图+OCR（看字）、`uiautomator dump`（看控件坐标）、探端口/日志（看服务）。
