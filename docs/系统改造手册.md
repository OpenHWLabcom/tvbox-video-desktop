# 系统改造手册 —— 把安卓机顶盒做成小主机（OpenHW Lab）

> 本手册是「视频追剧版桌面小电脑」的**完整操作原理与流程**，可人看，也可照着做。
> 目标是**复刻**到不同主板上：**瘦身 / 内存扩容 / 桌面 / 互传·U盘 / 浏览器 / 输入法**六件套 + 开机自愈。

## 核心约束（决定一切）
老盒子通常：**系统老（Android 4.4 / API19）、架构老（armv7 32 位或 arm64）、内存小（1GB）**。
所有取舍都围绕这三点。

---

## 0. 先调研（换机必做）
```sh
getprop ro.product.cpu.abi          # arm64 / armeabi-v7a —— 决定可用内核/浏览器
getprop ro.build.version.release; getprop ro.build.version.sdk
cat /proc/meminfo; df -k; mount      # 内存；分区；文件系统类型（swap 文件须放 ext4）
pm list packages                      # 能装三方 APK 吗
```
- 有 root、能开 ADB 是前提。
- 有些 ROM 的 TTL 串口「只出不进」，别指望串口敲命令，走 ADB/网络。

## 1. 控制通道（生命线）
- **ADB over TCP**（推荐）：盒子 `setprop service.adb.tcp.port 5555; /sbin/adbd &`，电脑 `adb connect <IP>:5555`。
  - 有的 ROM 的 init 没有 adbd 服务，只能手动 `/sbin/adbd &`。
  - 鉴权看 `/data/misc/adb/adb_keys`（只认已授权公钥）。
- **USB-TTL 串口**（备用）：115200 8N1，TX/RX 交叉、共地。串口卡顿时命令会排队、回显被吃。
- ⚠️ **别在命令行里放中文/密钥**（老内核会截断）→ 参数写进脚本再执行。

## 2. 文件互传通道（电脑 ⇄ 盒子）
- 电脑起静态服务：`python3 -m http.server 8099` → 盒子 `wget -O <路径> http://<电脑IP>:8099/文件`。
- 反向：盒子 `nc`/`scp` 发回；或截图 `screencap -p /data/x.png` 再拉回。
- 老 ROM 常用 `busybox wget`（自带的 busybox）。

## 3. 内存扩容（把存储当内存）
**分层交换**，越前面越快、越先用：
| 层 | 位置 | 大小 | 优先级 | 说明 |
|---|---|---|---|---|
| 1 | `zram0` | 512MB | -1 | 压缩内存，最快 |
| 2 | `/cache/swapfile` | 400MB | -2 | 磁盘层 |
| 3 | `/sdcard/swapfile` | 动态(空余60%，上限1.5GB) | -3 | 安全网 |
- 要点：① **swap 文件必须放 ext4**；② **先挂 zram 再挂文件**（优先级自动递减）；③ 动态分配时把「已有 swapfile 自身」算回可用空间，且**只增不减**；④ 幂等、可重复执行。
- 脚本见 `安装文件/2-内存扩容.sh`。

## 4. 瘦身
- 列三方应用：`pm list packages | grep -v /system`。
- 卸载：`pm uninstall <pkg>`（系统预装只能 `pm disable`）。
- 清垃圾：旧镜像/安装包/日志（先确认不是活动文件）。
- 只留业务功能 + 基础设施（桌面/输入法）。

## 5. Linux 子系统（当真正的 Linux 主机）
- 根文件系统放 `/data`（如 `/data/linux`），`losetup`+`mount` 挂载镜像后 `chroot`。
- 装 `openssh-server`、`python3`、`ntfs-3g`（认 U 盘）。
- ⚠️ **从 chroot 里跑 Android 的 `am/pm/settings/ime`**：必须回到 Android 根上下文并补 `BOOTCLASSPATH`，否则静默或 `Aborted`：
  ```sh
  chroot /proc/1/root /system/bin/sh -c 'export BOOTCLASSPATH=<从 system_server environ 取>; <cmd>'
  ```
- ⚠️ chroot 里看到的 `/data` 是 **rootfs 自带目录**，不是 Android 的 `/data`；写 Android `/data` 用 `/proc/1/root/data/...`。
- ⚠️ chroot 里的服务要带 **chroot 的 PATH**（否则子进程用安卓 PATH，找不到 `/usr/bin/*`）。

## 6. 桌面（原生 Android App）
- 桌面 App（`com.openhwlab.desktop`）：图标网格 + 双击打开 + 拖动吸附 + 右键菜单 + 顶栏（开始/任务/返回/关机）。
- 构建见 `从源码构建.md`；源码在 `开发者资料/桌面源码/`。
- 部署：`pm install -r 桌面.apk`。
- ⚠️ **改桌面代码后，仅 `pm install -r` + `force-stop` 不够**，旧进程会继续跑旧 dex → **必须重启盒子**。
- ⚠️ 改图标集合后，若位置错乱，清 `/data/data/<包名>/shared_prefs/*.xml`。
- 安卓 App 没有真窗口：「最小化/缩放」只能是页面内部的**伪窗口**（自绘标题栏 + 留边距）。

## 7. 局域网互传 + 外接 U 盘
- `transfer.py`（纯标准库）监听 `0.0.0.0:8890`：上传/下载/发文字/列表/预览。
- 无鉴权（仅限局域网）→ **别放隐私/密钥**。
- **U 盘**：这 ROM 的 `vold` 通常只认 FAT；**NTFS/exFAT** 要在子系统里用 `ntfs-3g` 手动挂到**子系统路径**（不要挂 Android 的 `/storage/sdX`）。
  - 重插后盘符会变（sda→sdb），用 `glob('/dev/block/sd*[0-9]')` 适配；会有「陈旧挂载」，先 umount 再重挂。
- ⚠️ **老 WebView = Chromium 30**：页面只用老 CSS（`inline-block`/`float`），**别用 grid/flex/object-fit**；缩略图用 `background-image`。
- ⚠️ USB 自动省电会让 U 盘/硬盘掉线 → `echo -1 > /sys/module/usbcore/parameters/autosuspend`。

## 8. 浏览器
- 界面语言跟**系统 locale** 走；要中文得装**多语言版**浏览器。
- 想要桌面版网页：给它的 profile 写 `user.js`（桌面 UA、视口宽度）。
- 老内核跑不动现代大网站 → 用简化页/原生 WebView 兜底，别强求。

## 9. 中文输入法
- 装一个带 arm 库的输入法（如搜狗 10.11）→ `ime set <输入法>` 启用（光 `settings put` 会被回落）。
- 「不弹软键盘」：本类 ROM 常无法只靠设置关软键盘 → 用桌面的「输入方式 = 实体键盘」来关掉所有输入法。

## 10. 显示设置 / 系统工具
- 本机服务 `:8899` 提供「关机/重启/任务切换/返回/关闭程序/显示(缩放/字体/输入法)」。
- 桌面的「显示设置」「系统清理」「程序和功能」都调它。

## 11. 开机自启 + 兜底
- 开个 链：init → `sh /data/startlinux.sh &` → 挂子系统 + 起服务 + `sh /data/bootfix.sh &`。
- **兜底**：这类 ROM 开机偶有「正在升级/正在启动」弹窗挡桌面 → `bootfix.sh` 反复「关系统弹窗 + 拉起桌面」直到桌面在前台。
- 复查：`dumpsys window windows | grep mCurrentFocus` 看前台是不是你的桌面包。

## 12. 验证手段（贯穿全程）
| 需求 | 手段 |
|---|---|
| 屏幕文字 | 截图 + OCR |
| 控件/坐标 | `uiautomator dump`（看 text/bounds） |
| 服务在跑 | 探端口 / 日志文件 |
| 开机自愈 | 重启后复查 |

## 关键坑（血泪）
1. 改桌面 App 必须**重启盒子**才生效。
2. 串口里别放中文/密钥；busybox 常缺 `head/free/ss/netstat`。
3. swap 文件必须 **ext4**；`/proc/swaps` 用**真实路径**比对。
4. 从 chroot 跑 `am/pm/settings/ime` 必须 `chroot /proc/1/root` + `BOOTCLASSPATH`。
5. 老 WebView 只吃老 CSS；USB 自动省电会掉盘。
6. 安卓 App 无真窗口；老内核上限决定能跑什么。

## 一句话
**先调研架构/系统/内存 → 打通 ADB 与互传 → 按「瘦身/扩容/桌面/互传/浏览器/输入法」六件套逐项上、每项都验证 → 记住"弱机瓶颈是内存与老内核"，能用现成开源方案就别重复造轮子。**
