# 从源码构建（桌面 App）

桌面是**纯原生 Android**（无第三方库），可以不用 Gradle 直接编译。

## 依赖
- **JDK 8+**（`javac` / `keytool` / `jarsigner`）
- **android.jar**（API 19 即可）
- **aapt**（build-tools 里的独立 aapt）
- **d8**（`d8.jar`，或 Android Gradle Plugin 的 D8）

> 都在 Android SDK：`build-tools/<ver>/{aapt,lib/d8.jar}`、`platforms/android-19/android.jar`。
> arm64/旧机器也可用解包的独立工具链。

## 编译
```bash
cd 桌面源码
# 仓库里的 build.sh 默认指向 /home/<你>/android-build 下的工具链；按需改顶部路径
./build.sh
# 产出 桌面.apk（包名 com.openhwlab.desktop）
```
`build.sh` 做的事：`javac` → `d8` → `aapt package` → `aapt add classes.dex` → `jarsigner`。

## 用 Android Studio / Gradle（可选）
把 `src/`、`AndroidManifest.xml`、`assets/` 放进一个标准工程：
- `minSdkVersion 17`、`targetSdkVersion 19`
- 权限：`INTERNET`、`SYSTEM_ALERT_WINDOW`、`READ_EXTERNAL_STORAGE`
- 入口：`MainActivity`（含 HOME + LAUNCHER intent-filter）
- 其它 Activity：`WebActivity`、`SettingsActivity`、`ProgramsActivity`、`CleanActivity`、`RecycleBinActivity`

## 代码结构（`src/com/openhwlab/desktop/`）
- `MainActivity` —— 桌面：图标网格、拖动/吸附、右键菜单、顶栏、开始菜单；调 `:8899` 做关机/重启/任务切换。
- `WebActivity` —— 通用网页窗口（原生 WebView，带窗口按钮）。
- `SettingsActivity` —— 显示设置（缩放/字体/输入方式），调 `:8899/cgi-bin/disp`。
- `ProgramsActivity` / `CleanActivity` / `RecycleBinActivity` —— 程序管理 / 清理 / 回收站。
- `BaseActivity` —— 公共基类。

## 注意
- 用 `Canvas.drawRoundRect(RectF,…)`（别用 API21 的 float 版）。
- 老 WebView 是 Chromium 30：页面只用老 CSS。
- 改了包名：同步改 `4-开机兜底.sh` 里的 `HOME_PKG`。

## 签名
`build.sh` 会自动生成 `desktop.keystore`（口令 `android`），保证「覆盖安装」签名一致。
想用自己的签名：改 `build.sh` 里的 keystore 路径与口令。
