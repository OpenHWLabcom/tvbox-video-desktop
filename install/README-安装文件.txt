========================================
  安装文件 · 说明（OpenHW Lab 视频追剧版桌面小电脑）
========================================

按顺序看：

先读顶层「安装教程.pdf」（图文），照着做即可。

本目录文件：

  一键安装.sh          ← 在电脑上跑：./一键安装.sh <盒子IP>
                          （推文件 + 装桌面 + 瘦身 + 扩容，一步到位）

  桌面.apk             ← 桌面程序（原生，无第三方依赖，离线）；装到机顶盒
  1-系统瘦身.sh        ← 去掉运营商/广告/无用后台（放到盒子 /data/瘦身.sh）
  2-内存扩容.sh        ← 存储当内存：zram + 分层 swap（放到 /data/扩容.sh）
  3-开机自启.sh        ← 开机自动挂 Linux 子系统 + 起服务（放到 /data/startlinux.sh）
  4-开机兜底.sh        ← 防卡在开机弹窗、确保桌面在前台（放到 /data/bootfix.sh）
  5-局域网互传.py      ← 手机⇄盒子 传文件（放到 Linux 子系统的 /root/transfer.py）
  6-系统工具服务.py    ← 桌面用的「关机/重启/显示设置」本机服务（放 /root/boxctl.py）

怎么用（两种）：
  A) 省事：连好 adb，直接跑  ./一键安装.sh <盒子IP>
  B) 手动：按「安装教程.pdf」一步步复制文件、执行命令（可照抄）

改包名/换设备：
  - 桌面 App 默认包名 com.openhwlab.desktop。
  - 若你自己重编了桌面（改了包名），记得同步改 4-开机兜底.sh 里的 HOME_PKG。
  - 脚本里的应用列表(瘦身)与路径(如 /data/linux)按你的机器改。
